# PLP Python Week 4

This repository contains my PLP Python Week 4 assignment.

* `welcome.py` - Contains a `welcome()` function that creates and prints welcome messages for different names.
* `toolbox.py` - Contains three functions: `double()`, `is_pass()`, and `greet()`.

The hardest function to write was `greet()` because it uses an optional greeting with a default value. I had to understand how function parameters can have default values and how to combine the greeting, name, comma, and exclamation mark correctly.
